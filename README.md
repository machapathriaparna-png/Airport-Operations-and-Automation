# Airport Operations & Automation – SQL Project

## Project Overview
The Airport Operations & Automation project is a MySQL-based database project designed to manage and analyze airport operations using SQL.

It demonstrates SQL concepts through structured queries, data analysis, stored procedures, triggers, and flight status monitoring.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Key Features
- Airport database and table management
- Flight operations analysis
- Data retrieval and filtering
- Joins and subqueries
- Views
- Stored procedures
- Triggers
- Automatic flight status logging
- Flight status change history
- Data validation and relationship checks

## Automation
A trigger automatically records flight status changes in the `Flight_Logs` table. It checks whether the flight status has changed before inserting a log entry.

## Project Structure
- `Airport_Operations.sql` – Main SQL project file containing the database creation, queries, analysis, and automation tasks.

## How to Run
1. Download or clone this repository.
2. Open MySQL Workbench.
3. Open `Airport_Operations.sql`.
4. Execute the SQL script section by section.
5. Verify the tables, query results, stored procedures, and triggers.

## Project Objective
The objective of this project is to strengthen practical SQL skills by working on an airport operations database and implementing automation using MySQL.
